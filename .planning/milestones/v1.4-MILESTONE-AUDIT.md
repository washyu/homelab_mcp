### Integration Gap — deploy_service_workflow Phantom Tool

`prompt_registry.py` line 114 instructs the agent:
```
2. Call list_installed_services with hostname="{target_host}" to check for conflicts...
```

`list_installed_services` is not registered in `TOOL_HANDLERS`, has no schema, and has no implementation in `src/`. An agent following this prompt will fail at step 2 with `ValueError: Unknown tool: list_installed_services`.

**Impact:** The deploy_service_workflow prompt is non-functional at step 2. The prompt itself exists and dispatches correctly; the referenced tool does not.
**Root cause:** Pre-existing since v1.2 (Phase 14). Not introduced by this milestone. No v1.4 requirement covers it.
**Closest valid tools:** `get_service_status` (checks running state) or `list_available_services` (lists installable services).
**Fix required:** Update prompt text to reference an existing tool, or implement `list_installed_services`.
