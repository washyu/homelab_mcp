<objective>
Remove phantom `port` property from 9 service tool schemas that declare it despite the underlying ServiceInstaller methods not accepting it.

Purpose: The service tool handlers use `**arguments` to pass schema properties directly to `ServiceInstaller` methods. Since those methods do not accept a `port` parameter, any MCP client that sends `port` triggers `TypeError: got an unexpected keyword argument 'port'` at runtime. This is the only category of schema-to-implementation mismatch in the codebase. (SSH tools also declare `timeout` in schemas without it being in function signatures, but this works correctly because `ssh_connection_wrapper` intercepts it via `kwargs.pop("timeout")`.)

Output: Service tool schemas with `port` removed; all other schemas verified as aligned.
</objective>
