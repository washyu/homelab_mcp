<objective>
Fix SSH tool schema-to-function mismatches: add explicit `timeout` parameter to `setup_remote_mcp_admin` and `verify_mcp_admin_access`, remove unused `timeout` from `ssh_execute_command` schema, and make `discover_and_map` username optional with default `mcp_admin`.

Purpose: The `ssh_connection_wrapper` decorator currently intercepts `timeout` via `kwargs.pop`, masking the mismatch. Adding `timeout` to function signatures makes the contract explicit and allows the functions to use it directly. For `ssh_execute_command`, the schema declares `timeout` but `**kwargs` absorbs it silently without effect — removing it is the honest fix. For `discover_and_map`, `username` is `required` while all peer SSH tools make it optional with keyring auto-injection.

Output: SSH tool schemas and functions with explicit, aligned parameter contracts.
</objective>
