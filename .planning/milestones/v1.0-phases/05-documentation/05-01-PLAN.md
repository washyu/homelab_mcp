**docs/configuration.md:**

Create a comprehensive configuration reference with these sections:

1. **Environment Variables** - Table format with columns: Variable, Default, Description, Category. Extract ALL variables from config.py (MCPConfig, HTTPConfig, DatabaseConfig classes) and run_server.py. Group by category:
   - **Server** - MCP_DEBUG (false), MCP_LOG_LEVEL (INFO)
   - **SSH** - SSH_TIMEOUT (10), SSH_RETRIES (3)
   - **Discovery** - DISCOVERY_BATCH_SIZE (10), DISCOVERY_TIMEOUT (300)
   - **Proxmox Connection** - PROXMOX_HOST (required), PROXMOX_USER (required), PROXMOX_PASSWORD, PROXMOX_API_TOKEN, PROXMOX_VERIFY_SSL (true), PROXMOX_CA_CERT
   - **HTTP Transport** - MCP_HTTP_ENABLED (false), MCP_HTTP_HOST (0.0.0.0 in config / 127.0.0.1 in CLI), MCP_HTTP_PORT (8080), MCP_API_KEY, MCP_AUTH_ENABLED (true), MCP_SSL_CERT, MCP_SSL_KEY
   - **Database** - DATABASE_TYPE (sqlite), SQLITE_PATH (~/.mcp/sitemap.db), POSTGRES_HOST, POSTGRES_PORT, POSTGRES_DB, POSTGRES_USER, POSTGRES_PASSWORD
   - **Feature Flags** - ENABLE_POSTGRESQL (false), ENABLE_RESOURCE_POOLS (false)

2. **CLI Arguments** - Document run_server.py arguments: --http, --host, --port, --no-auth, --api-key, --ssl-cert, --ssl-key. Note that CLI args override env vars.

3. **SSL Configuration** - How PROXMOX_VERIFY_SSL and PROXMOX_CA_CERT interact. How to use self-signed certs.

4. **Database Configuration** - SQLite (default) vs PostgreSQL setup.

Note the MCP_HTTP_HOST default discrepancy: config.py says 0.0.0.0 but run_server.py CLI default is 127.0.0.1. Document both: "When using --http CLI flag, default host is 127.0.0.1 (localhost only). When using MCP_HTTP_HOST env var, default is 0.0.0.0 (all interfaces)."
