    - validate_port(22) returns 22
    - validate_port(8006) returns 8006
    - validate_port(0) raises ValueError
    - validate_port(65536) raises ValueError
    - validate_port(-1) raises ValueError
    - validate_ip_network("192.168.1.0/24") returns "192.168.1.0/24"
    - validate_ip_network("not-a-network") raises ValueError
    - CredentialFilter redacts "password=secret123" to "password=[REDACTED]"
    - CredentialFilter redacts "token: abc123" to "token: [REDACTED]"
    - CredentialFilter redacts "PVEAPIToken=user@pam!tok=uuid" to "PVEAPIToken=[REDACTED]"
    - CredentialFilter redacts "Authorization: Bearer xyz" to "Authorization: [REDACTED]"
    - CredentialFilter redacts SSH private key blocks to [REDACTED]
    - CredentialFilter passes through messages without sensitive content unchanged
    - sanitize_error(Exception("password=secret")) returns string with [REDACTED]
    - sanitize_error(Exception("normal error")) returns "normal error" unchanged
  </behavior>
  <action>
    Write tests first in tests/test_validation.py and tests/test_log_filter.py covering all behaviors above.

    Then implement:

    1. **src/homelab_mcp/validation.py**: Create module with:
       - `_HOSTNAME_RE` compiled regex for RFC 1123 hostnames (1-63 char labels, no leading/trailing hyphens, total max 253). Accept internal TLDs like .local, .internal -- do NOT enforce valid TLDs.
       - `validate_hostname(value: str) -> str`: Try ipaddress.ip_address() first (handles IPv4 and IPv6), then hostname regex. Raise ValueError with clear message on failure.
       - `validate_port(value: int) -> int`: Accept 1-65535, raise ValueError otherwise.
       - `validate_ip_network(value: str, strict: bool = False) -> str`: Use ipaddress.ip_network() with strict parameter, raise ValueError on invalid.
       - All functions use Python stdlib only (ipaddress, re).

    2. **src/homelab_mcp/log_filter.py**: Create module with:
       - `_SENSITIVE_PATTERNS` list of (compiled_regex, replacement) tuples covering: password=, token=, token:, PVEAPIToken=, Authorization:, SSH private key blocks (BEGIN/END markers).
       - `CredentialFilter(logging.Filter)`: Override filter() to apply _SENSITIVE_PATTERNS to record.msg (if str) and record.args (if tuple of strings). Always return True (allow message through, just redacted).
       - `sanitize_error(error: Exception) -> str`: Apply _SENSITIVE_PATTERNS to str(error), return sanitized string.
       - Use patterns from research: `(password["\s:=]+)\S+`, `(token["\s:=]+)\S+`, `(PVEAPIToken=)\S+`, `(Authorization:\s*)\S+`, SSH key block pattern.

    Run tests after implementation. All must pass.
