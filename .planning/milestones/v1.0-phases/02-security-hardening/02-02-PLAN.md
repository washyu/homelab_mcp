<objective>
Flip Proxmox API connections from insecure-by-default to SSL-verified-by-default, with configurable override for self-signed certificates.

Purpose: SEC-02 ensures Proxmox API connections are not vulnerable to interception. Most homelabs use self-signed certs, so the override path (PROXMOX_VERIFY_SSL=false or PROXMOX_CA_CERT) must be clear and documented in error messages.
Output: Updated proxmox_api.py, config.py, resource_manager.py, and tests.
</objective>

  <name>Task 1: Add Proxmox SSL config and flip defaults to verify_ssl=True</name>
  <files>src/homelab_mcp/config.py, src/homelab_mcp/proxmox_api.py, tests/test_proxmox_api.py</files>
  <behavior>
    - ProxmoxAPIClient(host="pve") has verify_ssl=True by default
    - MCPConfig has proxmox_verify_ssl (bool, from PROXMOX_VERIFY_SSL env, default True)
    - MCPConfig has proxmox_ca_cert (str|None, from PROXMOX_CA_CERT env, default None)
    - MCPConfig.create_ssl_context() returns True when verify_ssl=True and no CA cert
    - MCPConfig.create_ssl_context() returns ssl.SSLContext when CA cert path is set
    - MCPConfig.create_ssl_context() returns False when verify_ssl=False
    - get_proxmox_client() uses new config defaults (verify_ssl=True)
    - get_proxmox_client() with PROXMOX_VERIFY_SSL=false sets verify_ssl=False
    - get_proxmox_client() with PROXMOX_CA_CERT set creates SSLContext with that CA
  </behavior>
  <action>
    Write tests first in tests/test_proxmox_api.py (add new test class or functions alongside existing tests):
    - test_ssl_verify_default_true: Create ProxmoxAPIClient with no args, assert verify_ssl is True
    - test_ssl_custom_ca_cert: Mock ssl.create_default_context, test that PROXMOX_CA_CERT env var creates SSLContext
    - test_ssl_verify_false_override: Set PROXMOX_VERIFY_SSL=false, verify get_proxmox_client has verify_ssl=False
    - test_config_ssl_defaults: MCPConfig() has proxmox_verify_ssl=True and proxmox_ca_cert=None

    Then implement:

    1. **src/homelab_mcp/config.py**: Add to MCPConfig.__init__():
       ```python
       # Proxmox SSL configuration
       self.proxmox_verify_ssl = os.getenv("PROXMOX_VERIFY_SSL", "true").lower() != "false"
       self.proxmox_ca_cert = os.getenv("PROXMOX_CA_CERT")
       ```

       Add method to MCPConfig:
       ```python
       def create_ssl_context(self) -> ssl.SSLContext | bool:
           """Create SSL context for Proxmox API connections.
           Returns True for system CA, False to disable, or SSLContext for custom CA."""
           if not self.proxmox_verify_ssl:
               return False
           if self.proxmox_ca_cert:
               import ssl
               return ssl.create_default_context(cafile=self.proxmox_ca_cert)
           return True
       ```

    2. **src/homelab_mcp/proxmox_api.py**:
       - Change `verify_ssl: bool = False` to `verify_ssl: bool = True` in ProxmoxAPIClient.__init__()
       - In `get_proxmox_client()` factory function, change the PROXMOX_VERIFY_SSL default from `"false"` to `"true"` and flip the logic: `verify_ssl = os.getenv("PROXMOX_VERIFY_SSL", "true").lower() != "false"`
       - Add CA cert support: read `PROXMOX_CA_CERT` env var, if set pass as `ssl_context` parameter
       - Update the connector creation in _do_request or session creation to pass `ssl=ssl_context` where ssl_context comes from config

    3. Run tests to verify.
