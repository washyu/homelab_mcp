       - `test_ssh_connect_rejects_invalid_port`: Call `ssh_connect("valid-host", port=99999)` and assert ValueError.
       - `test_ssh_connect_rejects_zero_port`: Call `ssh_connect("valid-host", port=0)` and assert ValueError.
       All tests use `@pytest.mark.asyncio` and call `await ssh_connect(...)` directly.
