  <behavior>
    - TOFU first connection: When connecting to a host with no entry in known_hosts, the key is accepted and stored
    - TOFU known key match: When connecting to a host whose key matches known_hosts, connection succeeds
    - TOFU key mismatch: When connecting to a host whose key differs from known_hosts, connection is rejected (validate_host_public_key returns False)
    - Known hosts file is created at ~/.homelab_mcp/known_hosts if it does not exist
    - Known hosts file uses OpenSSH format: "hostname key_type key_data" or "[hostname]:port key_type key_data" for non-22 ports
    - Concurrent TOFU to same host does not create duplicate entries (asyncio.Lock)
    - ssh_connect() passes known_hosts file path to asyncssh.connect
    - ssh_connect() passes client_factory=TOFUSSHClient to asyncssh.connect
    - ssh_connect() accepts hostname, username, port, password, key_path parameters
  </behavior>
  <action>

    Test structure:
    - test_tofu_first_connection: Mock asyncssh.SSHKey with export_public_key(). Create TOFUSSHClient with empty known_hosts file. Call validate_host_public_key() -> should return True. Verify key written to file.
    - test_tofu_accepts_known_key: Pre-populate known_hosts file with a host key. Create TOFUSSHClient. Do NOT call validate_host_public_key (asyncssh only calls it for keys NOT in the file -- the file-based check handles known keys). Instead verify that ssh_connect passes known_hosts=str(file_path) to asyncssh.connect.
    - test_tofu_rejects_mismatch: Pre-populate known_hosts with a key for host X. Create TOFUSSHClient. Call validate_host_public_key with a DIFFERENT key for host X -> should return False.
    - test_known_hosts_file_created: Call ssh_connect with a path that does not exist. Verify parent directory and file are created.
    - test_non_standard_port_format: Test that port 2222 uses "[host]:2222" format in known_hosts file, while port 22 uses plain "host".
    - test_ssh_connect_passes_correct_kwargs: Mock asyncssh.connect, call ssh_connect(), verify known_hosts and client_factory are passed.

    1. `KNOWN_HOSTS_PATH = Path.home() / ".homelab_mcp" / "known_hosts"` -- configurable via parameter but defaults to project directory.

    2. `_tofu_lock = asyncio.Lock()` -- module-level lock to prevent race conditions on concurrent TOFU (see research Pitfall 2).

    3. `TOFUSSHClient(asyncssh.SSHClient)`:
       - `__init__(self, known_hosts_path: Path)` -- store path
       - `validate_host_public_key(self, host, addr, port, key) -> bool` -- called by asyncssh when key is NOT in known_hosts file. Check if ANY key exists for this host in the file (key mismatch case). If yes, return False (reject). If no key exists at all, store the key and return True (TOFU accept). Use _tofu_lock for the file write.

       - `_store_host_key(self, host, port, key)` -- append to known_hosts file in OpenSSH format

       - Build connect_kwargs with: host, username, port, known_hosts=str(path), client_factory=lambda: TOFUSSHClient(path)
       - Add password and client_keys if provided
       - Return await asyncssh.connect(**connect_kwargs)

    IMPORTANT: Do NOT catch `known_hosts=""` or `known_hosts=None`. Always pass the explicit file path string per research Pitfall 1.

    - Replace with `connection = await ssh_connect(hostname=..., username=..., port=..., ...)`
