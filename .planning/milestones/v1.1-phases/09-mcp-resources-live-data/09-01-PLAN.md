<feature>
  <name>resource_readers module — live data fetchers for MCP resources</name>
  <files>src/homelab_mcp/resource_readers.py, tests/test_resource_readers.py</files>
  <behavior>
    read_vms_resource():
    - Returns {"vms": [...], "total": N, "scanned_at": "2026-...+00:00"} on success
    - Calls list_proxmox_resources(session=rm.proxmox_session) — do NOT pass host separately
    - Returns {"vms": [], "scanned_at": "...", "config_error": "..."} when PROXMOX_HOST not set (ValueError caught)
    - Returns {"vms": [], "scanned_at": "...", "error": "..."} when ResourceManager unavailable (RuntimeError caught)
    - Returns {"vms": [], "scanned_at": "...", "error": "..."} for any other exception
    - vms list comes from result["resources"] key of list_proxmox_resources return value
    - Includes "providers": ["proxmox"] to document data source

    read_devices_resource():
    - Returns {"devices": [...], "total": N, "scanned_at": "..."} on success
    - Each device dict is the raw db row PLUS "last_discovery_data" key
    - last_discovery_data = changes[0]["data"] from get_device_changes(device_id, limit=1), or None if no history
    - Returns {"devices": [], "scanned_at": "...", "error": "..."} when ResourceManager unavailable
    - Returns {"devices": [], "scanned_at": "...", "error": "..."} on DB exception

    read_service_resource(service_name: str):
    - Returns status dict with "scanned_at" injected: status["scanned_at"] = scanned_at
    - Hostname resolution order: 1) MCP_DEFAULT_SERVICE_HOST env var, 2) first device from DB with connection_ip or hostname
    - If no hostname resolvable: returns {"service": name, "status": "unconfigured", "reason": "...", "scanned_at": "..."}
    - If SSH fails: returns {"service": name, "status": "error", "hostname": h, "error": "...", "scanned_at": "..."}
    - Uses datetime.now(timezone.utc).isoformat() — NOT datetime.utcnow() (deprecated in 3.12)

    All three functions:
    - Use "from .server import get_resource_manager" as a local import inside the function body to avoid circular import
    - Use datetime.now(timezone.utc).isoformat() for scanned_at
    - Never let non-McpError exceptions propagate — always return graceful error payload
  </behavior>
