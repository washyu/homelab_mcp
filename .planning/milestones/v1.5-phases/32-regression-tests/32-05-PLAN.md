Reintroducing the exact pre-fix defect today would therefore NOT trigger the regression guard, violating the REG-01 contract for ROADMAP Success Criterion #4.

**Fix (from VERIFICATION.md — adopt exactly as specified):**

Rationale: in the context of a disjunctive `or` assert, a constant string literal being `in` ANY non-empty container is a tautology; the other branch is the actual check. The original all-Constant-comparator requirement was unnecessarily restrictive.

```python
def _is_structurally_always_true(node: ast.expr) -> bool:
    """Conservative truthy-constant detector.

    Flags ONLY shapes provably true at parse time. Dynamic expressions
    (Name, Call, Attribute, Compare over non-constants) are NOT flagged.
    """
    if isinstance(node, ast.Constant):
        # Non-empty string, non-zero number, True
        return bool(node.value)
    if isinstance(node, ast.BoolOp) and isinstance(node.op, ast.Or):
        return any(_is_structurally_always_true(v) for v in node.values)
    if isinstance(node, ast.Compare):
        # Compare over two Constants is evaluable at parse time
        if isinstance(node.left, ast.Constant) and all(isinstance(c, ast.Constant) for c in node.comparators):
            return True
    return False
```
