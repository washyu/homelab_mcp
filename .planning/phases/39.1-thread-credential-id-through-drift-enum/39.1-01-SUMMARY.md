## Decisions Made

- **Option B (side-map) over Option A (record-shape mutation).** Option A would have appended `proxmox_credential_id` to the 7-key probed_ok record, breaking the locked contract at `tests/test_drift_detection.py:699`. The plan's design_decision block documented this choice; execution honored it.
- **AST guard covers `drift_detection.py` only, not other modules.** Per threat model T-39.1-02, false-positive blast radius is limited. Future Proxmox-touching modules can add sibling guards.
- **`host_to_binding.get(h)` (not `host_to_binding[h]`) inside `_enum_one`.** Defensive `Mapping.get` returns None for missing keys, matching `get_proxmox_client(credential_id=None)` fallthrough semantics. A KeyError would crash the whole scan; falling through to Tier-1/Tier-2 cluster walk is safer.
