```python
def find_credential_by_id(credential_id: str) -> dict[str, str] | None:

        raise ValueError(f"credential_type must be 'ssh' or 'proxmox', got {credential_type!r}")

import json  # noqa: PLC0415  (or top of module)
import pathlib  # noqa: PLC0415
from datetime import UTC, datetime  # noqa: PLC0415

_MIGRATION_STATE_PATH = pathlib.Path.home() / ".homelab_mcp" / "migration_state.json"
_PHASE_38_1_KEY = "phase_38_1_credential_binding_applied"

def _load_migration_state() -> dict[str, Any]:
    if not _MIGRATION_STATE_PATH.exists():
        return {}
    try:
        return json.loads(_MIGRATION_STATE_PATH.read_text())
    except Exception:  # noqa: BLE001
        return {}

def _stamp_migration(key: str) -> None:
    state = _load_migration_state()
    state[key] = True
    state[f"{key}_at"] = datetime.now(UTC).isoformat()
    _MIGRATION_STATE_PATH.parent.mkdir(parents=True, exist_ok=True)
    _MIGRATION_STATE_PATH.write_text(json.dumps(state, indent=2))

def _phase_38_1_applied() -> bool:
    return bool(_load_migration_state().get(_PHASE_38_1_KEY))
```

def _auto_bind_credential(
    *,
    hostname: str,
    credential_type: str,
    new_credential_id: str,
) -> None:
    """D-04..D-07: auto-bind side effect for `credentials add`. Silent on no-match (D-01)."""
    import sys  # noqa: PLC0415
    from .sitemap import NetworkSiteMap  # noqa: PLC0415

    sitemap = NetworkSiteMap()
    matches = sitemap.db_adapter.execute_query(
        "SELECT id, hostname, connection_ip, "
        f"{credential_type}_credential_id AS current_binding "
        "FROM devices WHERE hostname = ? OR connection_ip = ?",
        (hostname, hostname),
    )
    if not matches:
        # D-01: silent — no warning
        return
    if len(matches) == 1:
        row = matches[0]
        if row["current_binding"] is None:
            sitemap.db_adapter.set_device_credential_binding(
                row["id"], credential_type, new_credential_id,
            )
        elif sys.stdin.isatty():
            answer = input(
                f"Sitemap row {row['hostname']!r} is already bound to a different "
                f"{credential_type} credential. Overwrite the mapping? [y/N]: "
            ).strip().lower()
            if answer == "y":
                sitemap.db_adapter.set_device_credential_binding(
                    row["id"], credential_type, new_credential_id,
                )
        else:
            # D-05: non-TTY → skip + warn
            print(
                f"Warning: sitemap row {row['hostname']!r} already bound to a different "
                f"{credential_type} credential; not rebinding (non-TTY).",
                file=sys.stderr,
            )
        return
    # D-06: multi-match
    if not sys.stdin.isatty():
        print(
            f"Warning: multiple sitemap rows match {hostname!r}; not auto-binding (non-TTY).",
            file=sys.stderr,
        )
        return
    print(f"Multiple sitemap rows match {hostname!r}:")
    for i, row in enumerate(matches, start=1):
        print(f"  [{i}] {row['hostname']} (ip={row['connection_ip']})")
    print("  [s] skip auto-bind")
    choice = input("Which row should this credential bind to? ").strip().lower()
    if choice.isdigit() and 1 <= int(choice) <= len(matches):
        picked = matches[int(choice) - 1]
        sitemap.db_adapter.set_device_credential_binding(
            picked["id"], credential_type, new_credential_id,
        )

## Shared Patterns

### Authentication (resolver short-circuit + actionable error messages)

**Source:** `src/homelab_mcp/proxmox_api.py:194-329` and `src/homelab_mcp/ssh_tools.py:80-188`.

**Apply to:** Every resolver call site. New `credential_id=` param is keyword-only, default `None`. Existing callers unchanged.

**Concrete excerpt — actionable-error pattern from `proxmox_api.py:322-329`:**
```python
raise CredentialNotFoundError(
    f"No Proxmox credentials found for {host}. "
    f"Cluster entries tried: {tried}. "
    f"Run `homelab-mcp credentials add --type proxmox {host} <username>` "
    "in your terminal to register this node explicitly, "
    "or run `homelab-mcp credentials add --type proxmox --scope cluster:<name> <token_id>` "
    "if this host belongs to a Proxmox cluster."
)
```
**D-11/D-12 messages must follow this shape:** what failed + recovery command.

### Error Handling (single exception class, context-based differentiation)

**Source:** `src/homelab_mcp/proxmox_api.py` `CredentialNotFoundError` (raised by both resolvers; caught by drift loop).

**Apply to:** All new D-11/D-12 raises in resolvers; drift's `except CredentialNotFoundError` → reason classification helper (see `_classify_credential_failure` above).

**D-12 lock:** **DO NOT** subclass `CredentialNotFoundError`. Differentiate via context (binding-was-passed? registry-lookup-hit?) or message-substring inspection.

### SQLite/Postgres adapter parity

**Source:** `src/homelab_mcp/database.py:24-85` (abstract base with `@abstractmethod`); `update_device_fingerprint` shape matched at SQLite 316-353 and Postgres 728-794.

**Apply to:** `set_device_credential_binding` (new abstract method) and `get_all_devices` (eligibility flatten).

**Adapter parity rule (Pitfall 3):** use `TEXT` for both `ssh_credential_id` and `proxmox_credential_id` columns. Postgres `UUID` type rejects malformed strings with `psycopg2.errors.InvalidTextRepresentation` — `TEXT` is uniformly nullable and accepts any string, matching SQLite.

**Postgres transaction shape (mandatory for read-modify-write):** `BEGIN` + `SELECT ... FOR UPDATE` + write + `commit`/`rollback` per `update_device_fingerprint` lines 756-794.

### CLI handler skeleton

**Source:** `src/homelab_mcp/server.py:519-744` (`_cmd_credentials_add`/`list`/`remove`).

**Apply to:** `_cmd_credentials_link` and `_cmd_credentials_unlink` and `_auto_bind_credential` helper.

**Conventions:**
- `import sys  # noqa: PLC0415` lazy import for stderr/exit.
- `print(..., file=sys.stderr)` for warnings/errors; `print(...)` for success on stdout.
- `sys.exit(1)` for unrecoverable errors with actionable error messages.
- `getattr(args, "as_json", False)` for optional flags (D-23 pattern).
