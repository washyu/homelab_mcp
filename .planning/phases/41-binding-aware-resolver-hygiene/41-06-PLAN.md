<objective>
Wave 5 (gap closure): Close 41-REVIEW.md CR-01 + WR-01 + WR-04 by splitting the resolver/cache key (hostname) from the TCP-dial target (connection_ip) on the drift Proxmox path. Today, Plan 41-04 set `host=row.connection_ip` on `get_proxmox_client`, which forwards into `resolve_proxmox_credentials(host=connection_ip, ...)` — that writes the telemetry cache as `_RESOLUTION_TELEMETRY_CACHE[(connection_ip, binding)]`. The very next block in `scan_drift` then reads `get_resolution_telemetry(hostname, binding)` — a guaranteed miss whenever `hostname != connection_ip`, defeating WR-04's double-resolve guard and risking `(scope, cluster_name)` mis-attribution when a row's hostname and IP resolve under different cluster scopes.

Fix: keep **hostname** as the canonical resolver/cache key everywhere on the drift call chain; add a separate `dial_host=` parameter to `get_proxmox_client` that flows through ONLY to the underlying `ProxmoxAPIClient(host=...)` TCP target. The resolver call inside `get_proxmox_client` continues to use `host=hostname`. This eliminates the cache-key inconsistency (CR-01), restores `_HOST_CLUSTER_CACHE` dedupe for cluster members (WR-01), and lets `get_resolution_telemetry(hostname, binding)` hit the entry populated by the same call.

Also: delete the unreachable `raise AssertionError(...)` at `drift_detection.py:541` and shrink the belt-and-braces comment per WR-04.

Add an AST guard locking the new invariant: any `get_proxmox_client(...)` call inside `drift_detection.py` that supplies `dial_host=` must also supply `host=` and `credential_id=`.

Purpose: Phase 41 ships incomplete if drift double-resolves credentials on every hostname≠connection_ip row (the common Bug-V case). The reviewer's preferred fix path (CR-01 §"Fix") is option (a) — split host from dial_host, keep hostname as resolver/cache key — because option (b) would also require flipping `_HOST_CLUSTER_CACHE` lookup keys and re-keying the `host_to_binding` map, with a much larger blast radius.

Output: `proxmox_api.py` extended (`get_proxmox_client` signature + ProxmoxAPIClient TCP dial path); `drift_detection.py` two call sites (`scan_drift` Proxmox loop + `_enumerate_proxmox_vms._enum_one`) + WR-04 cleanup; one regression test in `tests/test_drift_detection.py`; one AST guard class in `tests/test_ast_regression.py`.

Deferred (do NOT address in this plan): IN-01 (`_resolve_ssh_credentials_with_binding` dead code, ssh_tools.py:306-401), IN-02 (`ssh_discover_system_with_binding` superseded), IN-03 (`_parse_last_seen` UTC imprecision in sitemap.py). These are scheduled for a v1.8 cleanup phase per planning_context. Do NOT remove these helpers — they are load-bearing for back-compat call sites until the migration phase.
