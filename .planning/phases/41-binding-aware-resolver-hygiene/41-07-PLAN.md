Today (post Plans 41-04 / 41-06):
- `scan_drift` accepts `db_adapter: DatabaseAdapter` and uses it for `db_adapter.get_all_devices()` at line 706.
- `scan_drift` calls `_bulk_universal_core_probes(ssh_eligible_rows)` at line ~738 — does NOT forward `db_adapter`.
- `_bulk_universal_core_probes` defines a nested `_probe_one(row)` that calls `resolve_ssh_for_sitemap_row(hostname)` — no `db_adapter=` argument.
- `resolve_ssh_for_sitemap_row` (Plan 41-02) already accepts `db_adapter: DatabaseAdapter | None = None`. When `None` it falls through to `get_database_adapter()` (the production factory).
- Net: `_probe_one` re-constructs a brand-new SQLiteAdapter / PostgreSQLAdapter from `os.getenv("DATABASE_TYPE")` — potentially different connection / different db_path / different schema than the one `scan_drift` was handed.

Why this matters:
1. The `scan_drift` docstring explicitly promises `db_adapter` is "the single funnel for sitemap reads." Plumbing breaks this invariant inside the SSH pre-pass.
2. Test code that passes a `MagicMock` db_adapter expecting all sitemap reads to go through it sees `_probe_one`'s row lookup land on the production database instead — the gap is currently invisible because every drift test that exercises this path mocks out `_bulk_universal_core_probes` entirely.
3. In a multi-database deployment (Postgres dev / SQLite local), the same scan can read inconsistent rows from two databases.

Fix per 41-REVIEW.md WR-02 §"Fix":
```python
async def _bulk_universal_core_probes(
    rows: list[dict[str, Any]],
    *,
    db_adapter: DatabaseAdapter,
) -> dict[str, dict[str, Any]]:
    ...
    creds, matched_row = resolve_ssh_for_sitemap_row(
        hostname, db_adapter=db_adapter,
    )
```

This plan also adds a unit test that passes a MagicMock db_adapter into scan_drift and asserts the helper's row lookup was invoked on the mock (not on a real `get_database_adapter()` instance).

class TestPhase41DBAdapterHygiene:

      * .planning/phases/41-binding-aware-resolver-hygiene/41-REVIEW.md WR-02
      * .planning/phases/41-binding-aware-resolver-hygiene/41-07-PLAN.md
    """

    def _drift_resolve_calls(self) -> list[ast.Call]:
        src_root = Path(__file__).parent.parent / "src" / "homelab_mcp"
        source = (src_root / "drift_detection.py").read_text(encoding="utf-8")
        tree = ast.parse(source, filename="drift_detection.py")
        calls: list[ast.Call] = []
        for node in ast.walk(tree):
            if not isinstance(node, ast.Call):
                continue
            # Match unqualified ``resolve_ssh_for_sitemap_row(...)`` calls
            # (func is ast.Name) AND attribute-form calls (func is
            # ast.Attribute with .attr == name) — covers both ``from .ssh_tools
            # import resolve_ssh_for_sitemap_row`` and any future
            # ``module.resolve_ssh_for_sitemap_row`` shape.
            if isinstance(node.func, ast.Name) and node.func.id == "resolve_ssh_for_sitemap_row":
                calls.append(node)
            elif isinstance(node.func, ast.Attribute) and node.func.attr == "resolve_ssh_for_sitemap_row":
                calls.append(node)
        return calls
