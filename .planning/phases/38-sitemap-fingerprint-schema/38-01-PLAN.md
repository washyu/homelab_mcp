```python
# ─────────────────────────────────────────────────────────────────────
# Phase 38 D-04: fingerprint sub-dict (kernel + OS strings + dpkg digest).
# All three probes go through _run_with_timeout (Phase 35 D-05 / SC-4 — AST
# guard at tests/test_ast_regression.py:447 enforces). Missing tools cause
# the relevant key to stay absent; the existing partial:True flag (Phase 35
# D-09a) fires automatically via timed_out_commands.
# ─────────────────────────────────────────────────────────────────────
fingerprint_info: dict[str, Any] = {}

uname_s_result = await _run_with_timeout(
    conn, "uname -s", cmd_name="uname-s", timed_out=timed_out_commands
)
if uname_s_result and uname_s_result.exit_status == 0 and uname_s_result.stdout:
    fingerprint_info["kernel_name"] = cast(str, uname_s_result.stdout).strip()

uname_r_result = await _run_with_timeout(
    conn, "uname -r", cmd_name="uname-r", timed_out=timed_out_commands
)
if uname_r_result and uname_r_result.exit_status == 0 and uname_r_result.stdout:
    fingerprint_info["kernel_version"] = cast(str, uname_r_result.stdout).strip()

# Re-read /etc/os-release for the structured fingerprint.os_name/os_version
# fields (the existing PRETTY_NAME-only line at ~374-383 stays for the legacy
# system_info["os"] field per D-07 back-compat).
os_release_result = await _run_with_timeout(
    conn,
    "cat /etc/os-release 2>/dev/null",
    cmd_name="os-release-full",
    timed_out=timed_out_commands,
)
if os_release_result and os_release_result.exit_status == 0 and os_release_result.stdout:
    parsed: dict[str, str] = {}
    for line in cast(str, os_release_result.stdout).splitlines():
        if "=" not in line:
            continue
        key, _, value = line.partition("=")
        parsed[key.strip()] = value.strip().strip('"').strip("'")
    if parsed.get("PRETTY_NAME"):
        fingerprint_info["os_name"] = parsed["PRETTY_NAME"]
    elif parsed.get("NAME"):
        fingerprint_info["os_name"] = parsed["NAME"]
    if parsed.get("VERSION_ID"):
        fingerprint_info["os_version"] = parsed["VERSION_ID"]

# Locale-pinned dpkg digest for cross-locale reproducibility (Pitfall 1).
# sha256sum of stdin emits "<digest>  -" — strip the trailing field.
# Skip the empty-input sha (d41d8cd...) — that's what we get when dpkg is absent.
dpkg_result = await _run_with_timeout(
    conn,
    "LC_ALL=C dpkg -l 2>/dev/null | sort | sha256sum",
    cmd_name="dpkg-fingerprint",
    timed_out=timed_out_commands,
)
if dpkg_result and dpkg_result.exit_status == 0 and dpkg_result.stdout:
    digest_field = cast(str, dpkg_result.stdout).strip().split()[0]
    if digest_field and digest_field != "d41d8cd98f00b204e9800998ecf8427e":
        fingerprint_info["package_fingerprint"] = f"sha256:{digest_field}"

if fingerprint_info:
    system_info["fingerprint"] = fingerprint_info
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ssh_discover_system → remote SSH host | The probes execute on the remote host. Output is parsed in our process. |
| Remote stdout → fingerprint dict | Untrusted stdout text from `uname` / `cat /etc/os-release` / `dpkg`+`sha256sum`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-38-01-01 | Information Disclosure | dpkg-fingerprint probe | mitigate | The probe sends `dpkg -l` output through `sort | sha256sum` ON THE REMOTE host before transmission. Only the 64-char hex digest plus `  -` ever crosses the SSH channel — full package list never enters our process. (Verified: only `digest_field.split()[0]` is parsed.) |
| T-38-01-02 | Tampering | os-release parser | accept | Malicious /etc/os-release contents could inject ANSI escapes or oversized strings into `fingerprint.os_name`. Mitigation: the parser does `.strip().strip('"').strip("'")` per line; no shell evaluation; the value is JSON-serialized later (Plan 02), which is escape-safe. Risk is low because the trust boundary is "we already SSH'd in with credentials we own." |
| T-38-01-03 | Denial of Service | All three probes | mitigate | Every probe wrapped in `_run_with_timeout(timeout=10.0s)` (Phase 35 D-05) — a wedged dpkg/uname can't hang the discovery. Caps total Phase-38 added latency at 30s in the worst case. |
| T-38-01-04 | Tampering | LC_ALL=C dpkg pipeline | mitigate | The shell pipeline `LC_ALL=C dpkg -l 2>/dev/null | sort | sha256sum` is a static string — no parameter interpolation; nothing the remote host can do changes the command structure we send. Only the digest output can vary. |
| T-38-01-05 | Spoofing | Remote stdout impersonating valid output | accept | A compromised host could return fabricated `kernel_version` / `package_fingerprint` strings. Acceptable because the host is already trusted (we authenticated to it). Drift detection (Phase 39) is the consumer; if a host's fingerprint changes, the user investigates regardless of whether the change is "real" or "tampered." |
</threat_model>
