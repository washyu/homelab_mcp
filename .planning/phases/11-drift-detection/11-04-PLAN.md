  <behavior>
    - scan_drift(session, db_adapter, node=None, vm_type="all") is async, returns the full structured report
    - scan_drift iterates db_adapter.get_all_drift_baselines() to find VMs to compare
    - For each baseline: fetches live config via get_proxmox_vm_config; if config_drift found appends to report
    - For each baseline: fetches live status via get_proxmox_vm_status; if status != "running" adds state_drift finding with "observation": "vm_offline"
    - VMs with no baseline are NOT reported in config_drift (only counted in baselines_available summary)
    - update_baseline_after_mutation(node, vmid, vm_type, tool_name, session, db_adapter) fetches live config via get_proxmox_vm_config and calls db_adapter.upsert_drift_baseline
    - update_baseline_after_mutation silently logs and returns if get_proxmox_vm_config returns status=="error"
  </behavior>
  <action>
    Add to src/homelab_mcp/drift_detection.py (after _diff_vm_config):

    Implement `async def scan_drift(session: aiohttp.ClientSession | None, db_adapter: DatabaseAdapter, node: str | None = None, vm_type: str = "all") -> dict[str, Any]`:

    Algorithm:
    1. Set scan_timestamp = datetime.now(timezone.utc).isoformat()
    2. Call db_adapter.get_all_drift_baselines() — list of stored baselines
    3. Filter by node if node argument provided
    4. Filter by vm_type if vm_type != "all"
    5. For each baseline:
       a. Fetch live config: result = await get_proxmox_vm_config(node=b["node"], vmid=b["vmid"], vm_type=b["vm_type"], session=session)
          - If status=="error": log warning, skip config drift for this VM
          - If status=="success": call _diff_vm_config(b["baseline_config"], result["data"])
          - If changed_fields non-empty: append config_drift finding
       b. Fetch live status: result = await get_proxmox_vm_status(node=b["node"], vmid=b["vmid"], vm_type=b["vm_type"], session=session)
          - If status=="success" and result["data"].get("status") != "running":
            append state_drift finding with "observation": "vm_offline" (NEVER "confirmed_drift")
    6. Build and return summary dict with counts

    Implement `async def update_baseline_after_mutation(node: str, vmid: int, vm_type: str, tool_name: str, session: aiohttp.ClientSession | None, db_adapter: DatabaseAdapter) -> None`:

    Algorithm:
    1. Fetch live config: result = await get_proxmox_vm_config(node=node, vmid=vmid, vm_type=vm_type, session=session)
    2. If status=="error": logger.warning("Could not update drift baseline after %s: %s", tool_name, result["message"]); return
    3. Call db_adapter.upsert_drift_baseline(node=node, vmid=vmid, vm_type=vm_type, baseline_config=result["data"], recorded_by=tool_name)
    4. logger.debug("Drift baseline updated for %s:%s after %s", node, vmid, tool_name)

    CRITICAL: State drift observation label MUST be "observation": "vm_offline" — not any "confirmed_drift" variant.
