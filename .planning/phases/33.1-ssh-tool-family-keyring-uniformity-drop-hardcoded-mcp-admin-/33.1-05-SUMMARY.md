# 33.1-05 — AST Regression Guards (D-08 / D-09 / D-10)

## Goal

Extend `tests/test_ast_regression.py` with three narrow-scoped revert-proof guards so every decision landed in Phase 33.1 has a meta-test that fails at test time if a future change silently re-introduces the cleanup targets.

## Outcome

`tests/test_ast_regression.py` extended from 119 → 386 lines with:

- **D-08** — Function-signature AST scan flagging any `username='mcp_admin'` literal default in `src/homelab_mcp/**/*.py`, narrowed via a `DEFERRED_MCP_ADMIN_DEFAULT_FILES` file allowlist covering `ssh_connection.py` and `service_installer.py` (Phase 33.2 scope per user's "Narrow + defer" decision in 33.1-CONTEXT.md).
- **D-09** — Import-time recursive TOOLS-dict scan flagging any schema with a `password` property or a `username` property carrying `default='mcp_admin'` at any nesting depth (including `items.properties` for arrays). Narrowed via two tool allowlists:
  - `ALLOWED_PASSWORD_TOOLS` — the 3 SSH family tools (`ssh_discover`, `ssh_execute_command`, `start_interactive_shell`) plus 9 service tools, plus `create_proxmox_lxc` (container root password, deviation documented inline).
  - `ALLOWED_MCP_ADMIN_DEFAULT_TOOLS` — the 9 service tools. Empirical check confirmed no SSH tool carries the default today, so this allowlist is narrower than the plan skeleton's worst-case enumeration.
- **D-10** — Extended the existing `FORBIDDEN_SOURCE_STRINGS` list with `update_mcp_admin_groups` and `verify_mcp_admin_access`. Triggers the moment Plan 03 removes those identifiers.

Module docstring block points readers at ROADMAP Phase 33.2 and CONTEXT.md's deferred section. Every allowlist entry carries an inline `# Phase 33.2 scope` comment.
