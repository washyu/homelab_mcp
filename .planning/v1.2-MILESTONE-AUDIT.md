### Semantic Mismatch: PRMT-02

**Location:** `src/homelab_mcp/prompt_registry.py`, `_build_decommission_result()` ~line 78

**Issue:** `decommission_device_workflow` prompt instructs the AI to call `decommission_device_preview(hostname="...")` but both `decommission_device` and `decommission_device_preview` schemas declare `"required": ["device_id"]` — neither has a `hostname` property.

**Effect:** AI following the prompt will attempt `decommission_device_preview(hostname="...")` which fails schema validation with a missing-required-field error. An intermediate device-ID lookup step is needed but not included in the prompt.

**Test gap:** `test_decommission_workflow_prompt` asserts the string "decommission_device_preview" and "confirm" exist in the prompt text — it does not assert parameter names match the schema.

**Fix options:**
1. Add a lookup step: "First call `list_devices` to get the `device_id` for the target hostname, then call `decommission_device_preview(device_id=...)`"
2. Change prompt argument from `hostname` to `device_id` and update the template accordingly
